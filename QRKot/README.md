# Проект приложения для пожертвований QRKot
Проект представляет из себя вымышленный благотворительный фонд поддержки котиков QRKot, который собирает пожетвования на всевозможные задачи, связанные с помощью кошачей популяции: на корм, на медицинское обслуживание, организацию приютов и на другую помощь котам, кошкам и котятам.


## Авторы проекта:
    - backend: Кабардоков Марат

## Стек:
    - **backend**: python 3.12, alembic 1.7.7, fastapi 0.111.0, uvicorn 0.17.6

## Локальное развертывание:

### 1. Предварительные требования:

Клонировать репозиторий и перейти в него в командной строке:

```bash
git clone git@github.com:kamaramak/cat-charity-1.git
cd cat-charity-1
```

### 2. Запустить проект:

Cоздать и активировать виртуальное окружение:

```bash
py -3.12 -m venv env
```

* Если у вас Linux/macOS

    ```bash
    source venv/bin/activate
    ```

* Если у вас windows

    ```bash
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Примеры использования:

### Для запуска проекта:

```bash
uvicorn app.main:app
```
