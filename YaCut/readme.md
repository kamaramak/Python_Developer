# YaCut - Сервис для генерации коротких ссылок
Проект представляет из себя сервис по созданию коротких ссылок. На основе ссылки, предоставляемой пользователем, сервис генерирует короткую ссылку. Также пользователь может загрузить файлы в сервис и получить короткую ссылку для скачивания каждого отдельного файла.

## Авторы проекта:
    - backend: Кабардоков Марат
    - frontend: команда Яндекс Практикума, Кабардоков Марат

## Стек:
    - **backend**: python 3.12, Flask 3.0.2
    - **database**: SQLite

## Локальное развертывание:

### 1. Предварительные требования:

Клонировать репозиторий и перейти в него в командной строке:

```bash
git clone git@github.com:kamaramak/async-yacut.git
cd async-yacut
```

### 2. Запустить проект:

Cоздать и активировать виртуальное окружение:

```
py -3.12 -m venv env
```

* Если у вас Linux/macOS

    ```
    source venv/bin/activate
    ```

* Если у вас windows

    ```
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Создать в директории проекта файл .env с четыремя переменными окружения:

```
DISK_TOKEN=...
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=YOUR_SECRET_KEY
DATABASE_URI=sqlite:///db.sqlite3
```

Создать базу данных и применить миграции:

```
flask db upgrade
```

Запустить проект:

```
flask run
```

## Примеры использования:

# 1. Пользовательский интерфейс:

Для создания коротких ссылок из длинных ссылок перейти по адресу:

```url
http://127.0.0.1:5000/
```

Для создания коротких ссылок на файлы перейти по адресу:
```url
http://127.0.0.1:5000/files/
```

# 2. API:

Для создания коротких ссылок из длинных ссылок отправить POST- запрос на адрес:

```url
http://127.0.0.1:5000/api/id/
```

'''json
Пример запроса:
{
  "url": "string",
  "custom_id": "string"
}

Пример ответа:
{
  "url": "string",
  "short_link": "string"
}
'''

Для получения оригинальной ссылке по короткой ссылке отправить GET-запрос на адрес:

```url
http://127.0.0.1:5000/api/id/{short_id}
```

'''json
Пример ответа:
{
  "url": "string"
}
'''
