# 🏎️ F1 Telegram Bot

Telegram бот для просмотра календаря гонок Формулы-1, турнирных таблиц пилотов и кубка конструкторов.

## 📖 О проекте

Бот предоставляет актуальную информацию о чемпионате Формулы-1. Пользователи могут просматривать календарь гонок, личный зачет пилотов и кубок конструкторов за разные годы.

### Возможности
- 🗓 Календарь гонок с расписанием всех этапов сезона
- 👤 Турнирная таблица личного зачета пилотов
- 🏆 Кубок конструкторов
- 📅 Выбор года (от 1950 до текущего)
- 📱 Интерактивная пагинация для навигации по страницам
- 🔙 Удобная навигация между разделами
- 🌍 Автоматический перевод названий стран и городов

## 🛠 Технологии

- Python 3.12+
- aiogram 3.x
- asyncio
- third-party API (f1api.dev)
- googletrans
- emoji

## 🚀 Запуск проекта

### Локальный запуск
1. Клонировать репозиторий:
```bash
git clone https://github.com//f1-bot.git
cd f1-bot```

Установить зависимости:
```bash
pip install -r requirements.txt```

Создать файл .env:
```env
BOT_TOKEN=токен_твоего_бота```

Запустить:
```bash
python -m bot.main
Деплой на Railway```

Создать аккаунт на Railway
Подключить GitHub репозиторий
Добавить переменную окружения BOT_TOKEN
Railway автоматически развернет бота
